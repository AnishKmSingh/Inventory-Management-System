# Inventory-Management-System
Desktop Inventory Management System built with Python (Tkinter/ttkbootstrap) and MySQL. Tracks products, suppliers, customers, multi-location stock, purchase and sales orders with FIFO lot costing, audit logs, dashboard analytics and Excel export.
